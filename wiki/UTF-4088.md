# UTF-4088 Character System

**UTF-4088** is the project's character/semantic system. Beyond encoding
characters, it carries a semantic vocabulary the project uses for modeling
context, distribution, and determinism.

## Elements

| Element | Summary |
|---|---|
| **Historical Context Prior** | A prior grounding an item in historical context. |
| **Normal Distributive 3D Primer** | A distributive 3D priming construct. |
| **Model-Cycle Success Ratio** | A ratio describing success across model cycles. |
| **Polygraph-5 Semantic Falloff** | A semantic falloff measure (Polygraph-5). |
| **Branch Graph Vocabulary** | Vocabulary for branch-graph structure. |
| **Determinism** | UTF-4088 is deterministic. |

The related directory is
[`utf-4088/`](https://github.com/mearvk/Ubuntu.Determinant.Beta.Restricted/tree/main/utf-4088).

## Note on metaphor

As with the rest of the [core vocabulary](Proffer-and-Vocabulary), UTF-4088's
descriptive terms (e.g. semantic "falloff", "priming") are software-modeling
constructs, not claims about people or physical reality.
