## Scope

The **Tech II** designation applies to TAC3 installation and deployment technology, including installer-oriented configuration, deployment procedures, validation, and related operational documentation maintained under `tools/tac3/`.

It does not by itself establish:

- file ownership;
- filesystem ownership;
- process ownership;
- kernel authority;
- security trust status;
- cryptographic identity; or
- uniqueness of any TAC3 file or record.

Those properties remain governed by their respective TAC3 and operating-system mechanisms.

## Design Principle

The Installer Tech ID is administrative metadata about the technology and its current technical designation. It is intentionally separate from the TAC3 contextual identity model.

**Installer Tech ID ≠ File ID ≠ Context ID ≠ Owner ≠ Security/Trust Status.**

This separation preserves the TAC3 principle that a file is identified by its complete applicable context rather than by a single name or administrative notation.
