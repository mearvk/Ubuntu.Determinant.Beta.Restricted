# Desktop Wallpapers — Galactic Cherry Marvell Edition 98

9 original SVG wallpapers designed for the Galactic Cherry Marvell Edition.
All vector-based (SVG), resolution-independent, and render perfectly at any resolution from 1080p to 8K.

## Design Philosophy

- **Galactic** — deep space, stars, nebulae, cosmic scale
- **Cherry** — sakura blossoms, pink accents, petals, organic beauty
- **Marvell** — striking, elegant, something worth looking at

The combination represents technology (space/science) meeting nature (cherry blossom), held together by careful design.

## Technical Details

- Format: SVG 1.1 (supported by all modern X11/GTK/Qt compositors)
- ViewBox: 3840×2160 (4K native, scales to any resolution)
- No external dependencies or fonts
- GNOME integration via `galactic-cherry.xml` background properties
- File sizes: 2–5 KB each (total < 40 KB for all 9)

## Installation

```bash
make install DESTDIR=/
# Installs to /usr/share/backgrounds/galactic-cherry/
# And /usr/share/gnome-background-properties/galactic-cherry.xml
```

After installation, wallpapers appear in GNOME Settings → Appearance → Background.
